# AI Agent & 数字人对话系统项目

本项目为 AI Agent 与数字人对话问答系统的完整全栈项目仓库。包含 NestJS 后端服务与配套的前端 UI 界面。

---

## 📂 项目模块结构

本仓库目前已完成精简和整理，仅包含数字人与 RAG 核心相关的代码：

- **[digital-human-agent/](file:///Users/hewei/Documents/GitHub/ai-agent-course-code/digital-human-agent)**：数字人与企业级 RAG 检索问答系统的 **NestJS 后端服务**。实现了异步队列、多模态解析、RRF融合检索、双重记忆、ACL权限与知识图谱增强等。
- **[digital-human-agent-frontend/](file:///Users/hewei/Documents/GitHub/ai-agent-course-code/digital-human-agent-frontend)**：数字人与会话交互的 **前端 UI 界面**。
- **[docs/](file:///Users/hewei/Documents/GitHub/ai-agent-course-code/docs)**：项目相关的设计和执行技术文档。
